## 2. Описание файлов

### 📄 `python-ascii-animation-master.py`

**Назначение:** Основной скрипт для воспроизведения ASCII-анимации из файлов в папке `data/`.

**Ключевые функции:**
- Загрузка ASCII-кадров из текстовых файлов
- Циклическое воспроизведение анимации
- Очистка терминала между кадрами

**Логика работы:**
1. Определяет список файлов с ASCII-артами
2. Загружает содержимое каждого файла в список `frames`
3. В цикле выводит каждый кадр с задержкой 0.5 секунды
4. Очищает экран между кадрами для создания эффекта анимации

**Связи:** Зависит от файлов в папке `data/` для получения кадров анимации.

### 📄 `terminal_rain_lightning.py`

**Назначение:** Продвинутый скрипт симуляции дождя и грозы в терминале с использованием библиотеки `curses`.

**Ключевые классы:**

#### `Raindrop`
- **Поля:** `x`, `y`, `speed`, `char`
- **Назначение:** Представляет отдельную каплю дождя с позицией, скоростью и символом

#### `LightningBolt`
- **Поля:** `start_col`, `target_length`, `segments`, `is_growing`, `max_y`, `max_x`
- **Методы:**
  - `update()` - Обновляет состояние молнии, добавляет новые сегменты
  - `draw()` - Отрисовывает молнию на экране с учетом возраста сегментов

**Ключевые функции:**
- `setup_colors()` - Настройка цветовой схемы для дождя и молний
- `simulate_rain()` - Основной цикл симуляции
- `main()` - Точка входа с обработкой аргументов командной строки

**Логика работы:**
1. Инициализация curses-окна и цветов
2. Создание капель дождя с случайными параметрами
3. Генерация молний в режиме грозы
4. Обновление позиций объектов и отрисовка
5. Обработка пользовательского ввода

**Связи:** Независимый модуль, использует стандартные библиотеки Python.

### 📁 Папка `data/`

**Назначение:** Хранилище ASCII-артов для анимации.

**Содержимое:**
- `ascii1.txt` - `ascii10.txt` - Кадры анимации (ASCII-арт букв)
- `list.txt` - Пустой файл-список

**Формат файлов:** Обычные текстовые файлы с ASCII-символами, представляющими кадры анимации.

## 3. Архитектура проекта

### 🏗️ Общая структура

Проект состоит из двух независимых модулей:

1. **Простая ASCII-анимация** (`python-ascii-animation-master.py`)
   - Линейная архитектура
   - Чтение файлов → Загрузка в память → Циклическое воспроизведение

2. **Интерактивная симуляция** (`terminal_rain_lightning.py`)
   - Объектно-ориентированная архитектура
   - Система классов для объектов симуляции
   - Обработка пользовательского ввода в реальном времени

### 📊 Потоки данных

#### ASCII-анимация:
```
Файлы data/*.txt → Загрузка в frames[] → Цикл воспроизведения → Очистка экрана → Повтор
```

#### Симуляция дождя:
```
Инициализация → Основной цикл → Обновление объектов → Отрисовка → Обработка ввода → Повтор
```

## 5. Точка входа и запуск

### 🚀 Как запускается проект

#### ASCII-анимация:
```bash
python python-ascii-animation-master.py
```

**Что выполняется первым:**
1. Определение списка файлов ASCII-артов
2. Очистка терминала (`os.system('cls||clear')`)
3. Загрузка всех кадров в память
4. Запуск цикла воспроизведения

#### Симуляция дождя:
```bash
python terminal_rain_lightning.py [опции]
```

**Доступные опции:**
- `--rain-color COLOR` - цвет дождя (по умолчанию: cyan)
- `--lightning-color COLOR` - цвет молний (по умолчанию: yellow)
- `--help` - справка

**Что выполняется первым:**
1. Проверка поддержки TTY
2. Парсинг аргументов командной строки
3. Инициализация curses через `curses.wrapper()`
4. Запуск функции `simulate_rain()`

### 🎮 Управление

#### ASCII-анимация:
- Автоматическое воспроизведение
- Выход: `Ctrl+C`

#### Симуляция дождя:
- `t` или `T` - переключение режима грозы
- `q` или `Q` или `Esc` - выход
- `Ctrl+C` - выход
- Автоматическая адаптация к изменению размера терминала

## 6. Архитектурные особенности

### 🔧 Нестандартные решения

#### 1. **Гибридная архитектура**
Проект объединяет два разных подхода:
- **Простая линейная логика** для базовой ASCII-анимации
- **Объектно-ориентированный подход** для сложной симуляции

#### 2. **Система сегментов молний**
```python
# Уникальный подход к созданию реалистичных молний
segments = [(y, x, creation_time)]  # Каждый сегмент имеет время создания
```
- Молнии растут постепенно, а не появляются мгновенно
- Сегменты имеют "возраст" и исчезают через определенное время
- Система ветвления создает реалистичные разряды

#### 3. **Адаптивная генерация дождя**
```python
generation_chance = 0.5 if is_thunderstorm else 0.3
max_new_drops = cols // 8 if is_thunderstorm else cols // 15
```
- Интенсивность дождя зависит от режима (обычный/гроза)
- Количество капель адаптируется к размеру терминала

### 🎯 Причины выбора архитектуры

#### **Для ASCII-анимации:**
- **Простота:** Минимальный код для базовой функциональности
- **Производительность:** Загрузка всех кадров в память для быстрого воспроизведения
- **Совместимость:** Работает в любом терминале без дополнительных зависимостей

#### **Для симуляции дождя:**
- **Модульность:** Отдельные классы для разных объектов
- **Расширяемость:** Легко добавлять новые типы объектов
- **Производительность:** Эффективное управление объектами с помощью списков
- **Интерактивность:** Полная поддержка пользовательского ввода

### 🌟 Особенности реализации

#### **Система цветов:**
- Автоматическое определение поддержки цветов терминалом
- Fallback на черно-белый режим при отсутствии поддержки
- Настраиваемые цвета через аргументы командной строки

#### **Управление производительностью:**
- Контролируемая частота обновления (`UPDATE_INTERVAL = 0.015`)
- Ограничение количества активных молний (максимум 3)
- Эффективная очистка экрана с `stdscr.noutrefresh()` и `curses.doupdate()`

#### **Обработка ошибок:**
- Graceful handling ошибок curses
- Восстановление терминала при сбоях
- Информативные сообщения об ошибках
